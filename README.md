# SMILES Molecule Viewer (RDKit + Flask)

This app accepts a SMILES string from a simple web page and renders a 2D molecular structure as SVG, generated by a local Python backend using RDKit.

## What Was Implemented

- Created a frontend in `index.html` with:
  - SMILES input field
  - button to render the structure
  - status area for success/error feedback
  - inline SVG rendering area
- Created a backend in `app.py` with Flask + RDKit:
  - validates SMILES input
  - computes 2D coordinates
  - returns SVG through an API endpoint
- Added `requirements.txt` with required Python packages:
  - `flask`
  - `rdkit`
- Removed the download button to keep the UI simple and focused on rendering.

## Project Structure

- `index.html`: Frontend (input + SVG display)
- `app.py`: Backend/API (SMILES -> RDKit -> SVG)
- `requirements.txt`: Python dependencies

## API

- `GET /`
  - Returns `index.html`
- `GET /api/render?smiles=<SMILES>`
  - Returns SVG (`image/svg+xml`) for valid SMILES
  - Returns JSON error for missing/invalid input

## Run the Project

```bash

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py
```

Then open:

- `http://127.0.0.1:5000`

## Troubleshooting

You are most likely not running inside the virtual environment. Confirm that `(.venv)` is visible in your terminal, then reinstall dependencies:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### RDKit installation fails with pip

RDKit can be platform-sensitive. If `pip install rdkit` fails, use a conda/mamba environment instead.
